# 04 — RAM, ROM e BIOS

## 1. Memória RAM

RAM significa Random Access Memory, ou memória de acesso aleatório.

Ela mantém temporariamente dados e instruções utilizados pelo computador.

Características:

- É rápida.
- Permite leitura e escrita.
- É volátil.

Exemplo: quando um programa está aberto, parte dos dados necessários para sua execução fica na RAM.

## 2. Memória ROM

ROM significa Read-Only Memory, ou memória somente de leitura.

Tradicionalmente, é uma memória não volátil utilizada para guardar instruções importantes.

Computadores modernos também utilizam memória flash para armazenar firmware, permitindo atualizações.

## 3. BIOS

BIOS significa Basic Input/Output System.

É um firmware responsável por tarefas iniciais realizadas quando o computador é ligado.

Nos computadores modernos, normalmente é utilizado o UEFI, sucessor da BIOS tradicional. Mesmo assim, é comum chamar as configurações do firmware de BIOS.

## 4. Inicialização do computador

De forma simplificada:

1. O computador é ligado.
2. O firmware BIOS/UEFI começa a funcionar.
3. Os componentes são inicializados e verificados.
4. O firmware procura um dispositivo de inicialização.
5. O carregador inicia o sistema operacional.
6. O sistema operacional prepara o computador para uso.

## 5. Diferenças

- RAM: memória temporária utilizada durante a execução.
- ROM: categoria tradicional de memória não volátil.
- BIOS/UEFI: firmware que realiza tarefas importantes durante a inicialização.

## Resumo

RAM, ROM e BIOS são conceitos diferentes. A RAM mantém dados temporários, a ROM é uma categoria de memória não volátil e a BIOS/UEFI ajuda a inicializar o computador.
