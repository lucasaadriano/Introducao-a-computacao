# 09 — Revisão de Conceitos

## 1. Computação

A computação estuda o processamento de dados e a resolução de problemas utilizando sistemas computacionais.

## 2. Hardware e software

- Hardware: componentes físicos, como CPU, RAM, teclado e SSD.
- Software: programas e instruções, como sistemas operacionais e aplicativos.

## 3. Algoritmos

Um algoritmo é uma sequência organizada de passos para resolver um problema. Ele pode receber dados, processá-los e produzir uma saída.

## 4. Armazenamento de dados

- RAM: mantém temporariamente dados e instruções em uso.
- ROM: categoria tradicional de memória não volátil.
- SSD e HD: armazenam dados de forma persistente.

## 5. Representação de informações

Os computadores representam informações digitalmente. Um bit pode assumir 0 ou 1, e um byte contém 8 bits.

## 6. Sistemas numéricos

- Decimal: base 10.
- Binário: base 2.
- Octal: base 8.
- Hexadecimal: base 16.

Exemplo: `1010₂ = 10₁₀`.

## 7. Portas lógicas

- AND: 1 quando todas as entradas são 1.
- OR: 1 quando pelo menos uma entrada é 1.
- NOT: inverte o valor.
- XOR: 1 quando as entradas são diferentes.
- NAND: AND invertida.
- NOR: OR invertida.

## 8. Circuitos digitais

Circuitos digitais combinam componentes e portas lógicas para processar sinais binários.

## 9. CPU

A CPU executa instruções e processa dados. A Unidade de Controle coordena operações, a ULA realiza cálculos e operações lógicas, e os registradores guardam valores temporários.

## 10. Programa armazenado

O conceito de programa armazenado consiste em manter instruções na memória para que a CPU possa buscá-las e executá-las.

## 11. Harvard e Von Neumann

Na organização clássica Von Neumann, instruções e dados compartilham a mesma memória principal. Na arquitetura Harvard, instruções e dados utilizam memórias separadas.

## 12. RAID

RAID combina dispositivos de armazenamento para buscar objetivos como desempenho, redundância ou tolerância a falhas, dependendo do nível utilizado.

## Resumo geral

Os dados são representados digitalmente e armazenados em memórias ou dispositivos de armazenamento. A CPU executa instruções para processar os dados. Algoritmos descrevem passos para resolver problemas, e programas implementam esses passos. Portas lógicas e circuitos digitais são fundamentais para o funcionamento do hardware.
