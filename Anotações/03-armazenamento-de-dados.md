# 03 — Armazenamento de Dados

## 1. O que é armazenamento de dados?

Armazenar dados significa registrar informações para que possam ser utilizadas posteriormente.

Os computadores possuem diferentes tipos de memória e dispositivos de armazenamento.

## 2. Memória RAM

A RAM é utilizada para manter temporariamente dados e instruções necessários aos programas em execução.

Características:

- É rápida.
- Permite leitura e escrita.
- É volátil: normalmente perde seu conteúdo quando o computador é desligado.

Exemplo: quando abrimos um navegador, parte dos dados necessários para seu funcionamento fica na RAM.

## 3. SSD e HD

**SSD:** dispositivo que utiliza memória flash para armazenar arquivos e programas.

**HD:** dispositivo que utiliza discos magnéticos para armazenar dados.

Os dois mantêm os dados mesmo quando o computador está desligado.

## 4. Como funcionam juntos?

Imagine que você abra um documento salvo no SSD:

1. O arquivo está armazenado no SSD.
2. Os dados necessários são carregados na RAM.
3. A CPU executa as instruções do programa.
4. Ao salvar alterações, os dados atualizados são gravados no armazenamento.

## 5. Unidades de medida

- Bit (b): unidade básica que representa 0 ou 1.
- Byte (B): conjunto de 8 bits.
- KB: quilobyte.
- MB: megabyte.
- GB: gigabyte.
- TB: terabyte.

Na convenção decimal, 1 KB corresponde a 1.000 bytes. Na convenção binária, 1 KiB corresponde a 1.024 bytes.

## 6. Memória volátil e não volátil

**Volátil:** precisa de energia para manter os dados, como a RAM convencional.

**Não volátil:** mantém os dados sem energia, como SSDs, HDs e memória flash.

## Resumo

A RAM mantém temporariamente dados e instruções utilizados durante a execução dos programas. SSDs e HDs armazenam arquivos de forma persistente.
