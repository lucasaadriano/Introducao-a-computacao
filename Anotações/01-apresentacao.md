# 01 — Apresentação: Introdução à Computação

## 1. O que é computação?

A computação é a área que estuda o processamento de dados e a resolução de problemas utilizando computadores e outros sistemas computacionais.

Ela envolve o estudo de hardware, software, algoritmos, dados e diferentes tecnologias utilizadas para processar informações.

A computação está presente em diversas atividades do nosso cotidiano, como utilizar celulares, acessar a internet, jogar videogames, realizar pagamentos digitais e desenvolver programas.

## 2. O que é um computador?

Um computador é uma máquina eletrônica capaz de receber dados, processá-los de acordo com instruções, armazenar informações e apresentar resultados.

De maneira simplificada, seu funcionamento pode ser dividido em quatro etapas:

1. **Entrada:** recebimento dos dados.
2. **Processamento:** realização de operações com os dados.
3. **Armazenamento:** conservação dos dados e resultados.
4. **Saída:** apresentação dos resultados.

### Exemplo prático

Imagine que você utilize uma calculadora para somar dois números:

- Entrada: os números 5 e 3.
- Processamento: a operação de soma.
- Resultado: o número 8.
- Saída: a apresentação do resultado na tela.

## 3. Hardware

Hardware é o nome dado aos componentes físicos de um computador, ou seja, às partes que podemos tocar.

Exemplos de hardware:

- **CPU:** executa instruções e processa dados.
- **Memória RAM:** armazena temporariamente dados e instruções em uso.
- **SSD e HD:** armazenam arquivos e programas.
- **Placa-mãe:** conecta e permite a comunicação entre diversos componentes.
- **Teclado:** permite inserir dados e comandos.
- **Monitor:** apresenta informações visualmente.

## 4. Software

Software é o conjunto de programas, instruções e dados utilizados para realizar tarefas em um computador.

Diferentemente do hardware, o software não corresponde a uma peça física.

Exemplos de software:

- Windows e Linux: sistemas operacionais.
- Google Chrome: navegador de internet.
- Microsoft Word: editor de textos.
- Python: linguagem de programação e ambiente utilizado para executar programas.
- Jogos e aplicativos: programas desenvolvidos para diferentes finalidades.

## 5. Diferença entre hardware e software

Hardware e software são diferentes, mas trabalham juntos.

O hardware fornece os componentes físicos necessários para o funcionamento do computador. O software contém as instruções que orientam o computador a realizar determinadas tarefas.

### Exemplo

Quando você abre um navegador:

1. O sistema operacional inicia o programa.
2. A CPU executa as instruções necessárias.
3. A memória RAM mantém temporariamente dados utilizados pelo programa.
4. O monitor apresenta a interface do navegador.

Nesse exemplo, o navegador é um software, enquanto a CPU, a RAM e o monitor são componentes de hardware.

## 6. O que são dados e informações?

**Dados** são valores ou registros que podem ser processados por um sistema computacional.

**Informações** são dados interpretados dentro de um contexto, de forma que tenham significado para alguém.

### Exemplo

Considere o número:

`25`

Sozinho, ele não informa o que está sendo medido.

Agora considere:

`A temperatura da sala é de 25 °C.`

Nesse caso, o valor foi apresentado em um contexto que permite compreender seu significado.

## 7. O que é processamento de dados?

O processamento de dados consiste em realizar operações sobre dados para produzir resultados.

Essas operações podem envolver cálculos matemáticos, comparações, organização de registros e execução de instruções.

### Exemplo prático

Uma escola deseja calcular a média de um aluno que obteve as notas 8 e 6.

Primeiro, as notas são recebidas:

`8 e 6`

Depois, são somadas:

`8 + 6 = 14`

Em seguida, o resultado é dividido pela quantidade de notas:

`14 / 2 = 7`

A média do aluno é 7.

## 8. O que é programação?

Programação é o processo de desenvolver programas por meio da criação de instruções que um computador pode executar.

Essas instruções são escritas utilizando linguagens de programação, como Python, Java, C e JavaScript.

### Exemplo em Python

```python
numero1 = 5
numero2 = 3

resultado = numero1 + numero2

print(resultado)
```

Resultado:

```text
8
```

Nesse programa:

- `numero1` guarda o valor 5.
- `numero2` guarda o valor 3.
- `resultado` recebe a soma dos dois números.
- `print()` apresenta o resultado na tela.

## 9. Por que estudar computação?

Estudar computação ajuda a compreender como os computadores funcionam, como os dados são processados e como os programas são desenvolvidos.

Na Ciência da Computação, esses conhecimentos servem como base para assuntos mais avançados, como programação, algoritmos, bancos de dados, sistemas operacionais, redes de computadores e inteligência artificial.

## Resumo

A computação estuda o processamento de dados e a resolução de problemas utilizando sistemas computacionais. O hardware corresponde aos componentes físicos do computador, enquanto o software corresponde aos programas e às instruções executadas por ele. Os computadores recebem dados, processam informações, armazenam resultados e apresentam saídas.
