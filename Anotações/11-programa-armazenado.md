# 11 — Conceito de Programa Armazenado

## 1. O que é um programa armazenado?

O conceito de programa armazenado consiste em manter as instruções de um programa na memória do computador para que possam ser buscadas e executadas pela CPU.

Isso permite que o mesmo computador execute diferentes programas sem precisar modificar fisicamente seus circuitos para cada tarefa.

## 2. Como funciona?

1. Um programa fica guardado em um dispositivo, como um SSD.
2. Quando necessário, suas instruções são carregadas na memória.
3. A CPU busca as instruções.
4. A CPU interpreta e executa as instruções.
5. Os resultados são produzidos e podem ser armazenados ou apresentados ao usuário.

## 3. Exemplo prático

Imagine dois programas:

- Programa A: soma dois números.
- Programa B: calcula a média de duas notas.

Os dois podem ser armazenados e executados pelo mesmo computador. O hardware continua o mesmo, mas as instruções executadas são diferentes.

## 4. Por que esse conceito é importante?

O programa armazenado torna o computador flexível. Em vez de construir um circuito físico diferente para cada tarefa, podemos armazenar instruções e executar programas distintos no mesmo hardware.

## 5. Relação entre CPU e memória

A memória mantém instruções e dados necessários à execução. A CPU busca as instruções, interpreta o que precisa ser feito e executa as operações.

## Resumo

O conceito de programa armazenado permite guardar instruções na memória para que a CPU possa executá-las. Isso permite que o mesmo computador realize diferentes tarefas por meio de diferentes programas.
